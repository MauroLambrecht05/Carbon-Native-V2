# carbon-templates

Curated production starter templates for Carbon Native desktop applications.

## Available Templates

| ID | Name | Category | Description |
|---|---|---|---|
| `tray-daemon` | System Tray Daemon | `desktop-utility` | Background menubar / system tray utility with context menus and window toggling |
| `database-studio` | Database Studio Client | `developer-tool` | Admin console connected to Carbon Database with table inspector and SQL editor |
| `realtime-chat` | Realtime Chat Client | `communication` | Cross-platform desktop chat app with channel sidebar and message feed |
| `audio-station` | Native Audio Station | `media` | Low-latency audio player and waveform console |

## Usage with CLI

```sh
carbon init my-app --template tray-daemon
carbon init my-studio --template database-studio
```
